## Descrição da atividade

Este projeto consiste em um mini catálogo de filmes e séries desenvolvido com HTML e JavaScript.

Foram utilizados iterators do JavaScript para realizar:

- Listagem de dados com `forEach`
- Transformações com `map`
- Filtros com `filter`
- Buscas com `find`
- Agregações com `reduce`
- Verificações com `some` e `every`

Os resultados são exibidos:

- No Console do navegador
- Na página HTML dentro da `div#output`
